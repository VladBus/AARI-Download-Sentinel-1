# AARI-Download-Sentinel-1

Автоматизация поиска и загрузки исходных продуктов Sentinel-1 для рабочей территории Северного морского пути (СМП).

## Текущий этап разработки

Реализовано:

- конфигурация проекта через локальный файл .env;
- построение поисковой области СМП с буфером 150 км;
- обработка пересечения 180-го меридиана;
- лёгкая проверка доступа к CDSE S3 без скачивания данных;
- поиск Sentinel-1 EW GRDM с HH+HV через CDSE OData;
- раздельные запросы для частей полигона по обе стороны 180-го меридиана;
- обработка пагинации OData и устранение повторов;
- сохранение результатов поиска в локальный JSON;
- модульные тесты конфигурации, геометрии, OData и S3.

На этом этапе скачивание полных SAFE-продуктов ещё не включено. Поиск и проверка S3 не загружают снимки на диск.

## Требования

- Windows 10/11 x64;
- Python 3.14 (разработка ведётся на Python 3.14.3);
- виртуальное окружение .venv;
- учётная запись Copernicus Data Space Ecosystem;
- действующие S3 Access Key и Secret Key для проверки хранилища и последующей загрузки.

Параметр `CDSE_S3_CHECK_PREFIX` по умолчанию установлен в `Sentinel-1/SAR/EW_GRDM_1S/`, то есть в каталог EW GRDM, соответствующий целевому типу продукта.

## Первоначальная настройка

В корне проекта:

~~~powershell
py -3.14 -m venv .venv
.\.venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
~~~

Создайте локальный файл конфигурации:

~~~powershell
Copy-Item .env.example .env
~~~

Если терминал открыт в cmd.exe, используйте:

~~~bat
copy .env.example .env
~~~

В .env заполните CDSE_ACCESS_KEY и CDSE_SECRET_KEY. Никогда не добавляйте реальные ключи в Git.

Поместите рабочий файл SMP.geojson сюда:

~~~text
data\geometry\SMP.geojson
~~~

Исходная геометрия, поисковые результаты, логи и скачанные данные исключены из Git.

## Проверка CDSE S3

~~~powershell
python main.py --check-s3
~~~

Команда выполняет один запрос ListObjectsV2 к бакету eodata с префиксом Sentinel-1/SAR/EW_GRDM_1S/ и MaxKeys=1. Этот префикс соответствует S3Path продуктов, полученных в тестовом OData-поиске. Она проверяет авторизацию и права листинга, не скачивая снимки.

## Проверка точного S3-префикса продукта

После поиска OData можно проверить один продукт по его точному S3Path из JSON-отчёта:

~~~powershell
python main.py --check-s3-product --search-report data\search_results\sentinel1_EW_GRDM_1S_DH_2026-11-24_2026-11-25.json --product-index 0
~~~

Команда перечисляет максимум пять объектов внутри выбранного SAFE-префикса. Она не скачивает снимок. Если объекты найдены, выводятся имена ключей и размеры файлов. Если список пуст, проверьте другой продукт из того же отчёта параметром --product-index.

## Поиск Sentinel-1

Укажите даты в формате YYYY-MM-DD. Конечная дата включается в поиск.

~~~powershell
python main.py --search-s1 --start-date 2026-11-10 --end-date 2026-11-12
~~~

По умолчанию поиск выполняется для:

- коллекции SENTINEL-1;
- типа продукта EW_GRDM_1S;
- поляризационного кода DH (HH+HV);
- геометрии из data\geometry\SMP_search_area_150km.geojson;
- максимума 500 продуктов.

OData запрашивает каждую часть поисковой геометрии отдельно. Результаты объединяются по идентификатору продукта. Обрабатываются все страницы ответа до достижения лимита или окончания результатов.

Пример с другим лимитом:

~~~powershell
python main.py --search-s1 --start-date 2026-11-10 --end-date 2026-11-12 --max-products 200
~~~

Полный результат записывается в data\search_results\ в формате JSON. В терминале выводятся количество найденных продуктов, параметры запроса и первые 20 результатов с именами и S3Path.

Важно: результат OData — это список найденных продуктов, а не скачанные файлы. Массовая загрузка будет добавлена отдельным этапом после проверки поисковой выдачи и S3-доступа.

## Подготовка поисковой области вручную

~~~powershell
python main.py --prepare-region
~~~

Или с другим буфером:

~~~powershell
python main.py --prepare-region --buffer-km 150
~~~

По умолчанию создаётся data\geometry\SMP_search_area_150km.geojson. Буфер рассчитывается в EPSG:3995, а затем возвращается в WGS84 с разделением по 180-му меридиану.


## Безопасность

- .env содержит персональные ключи и исключён из Git.
- data/ и logs/ исключены из Git.
- Не публикуйте Secret Key, Access Key ID и рабочие геоданные без разрешения.
- Секреты не выводятся в логах и отчётах.

## План дальнейшей разработки

1. Проверка S3 и тестовый поиск OData (текущий этап).
2. Скачивание полного SAFE-продукта с проверкой целостности и возобновлением прерванной загрузки.
3. Защита от повторного скачивания, журналирование и ежедневный запуск через Windows Task Scheduler.
4. Постобработка SAR-продуктов (отдельный этап).
