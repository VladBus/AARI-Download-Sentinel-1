# AARI-Download-Sentinel-1

Автоматизация поиска и загрузки исходных продуктов Sentinel-1 для рабочей территории Северного морского пути (СМП).

## Текущий этап разработки

На первом этапе реализованы:

- базовая конфигурация проекта через файл .env;
- подготовка рабочей области СМП на основе исходного GeoJSON;
- буферизация на 150 км наружу от исходной границы;
- обработка пересечения 180-го меридиана;
- сохранение итоговой поисковой геометрии в GeoJSON;
- модульные тесты геометрии и конфигурации.

Поиск продуктов через OData и загрузка через S3 будут добавлены следующим этапом.

## Требования

- Windows 10/11 x64;
- Python 3.14 (разработка ведётся на Python 3.14.3);
- виртуальное окружение .venv;
- учётная запись Copernicus Data Space Ecosystem и действующие S3 Access Key / Secret Key для последующей загрузки.

## Первоначальная настройка

Откройте терминал в корне проекта и выполните:

~~~powershell
py -3.14 -m venv .venv
.\.venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
~~~

Скопируйте шаблон переменных окружения:

~~~powershell
Copy-Item .env.example .env
~~~

Откройте файл .env и заполните CDSE_ACCESS_KEY и CDSE_SECRET_KEY значениями из CDSE S3 Credentials Manager. Секретный ключ нельзя публиковать или отправлять в GitHub.

Положите рабочий файл SMP.geojson в каталог:

~~~text
data\geometry\SMP.geojson
~~~

Исходная геометрия и скачанные данные являются локальными рабочими материалами и не добавляются в Git.

## Подготовка поисковой области

~~~powershell
python main.py --prepare-region
~~~

Или через BAT-файл:

~~~powershell
.\run_sentinel1.bat --prepare-region
~~~

По умолчанию создаётся:

~~~text
data\geometry\SMP_search_area_150km.geojson
~~~

Буфер строится в полярной стереографической проекции EPSG:3995, затем геометрия возвращается в WGS84. Пересечение 180-го меридиана разделяется на отдельные полигоны, чтобы избежать некорректных географических колец в запросах к каталогу.

Ширину буфера можно переопределить параметром:

~~~powershell
python main.py --prepare-region --buffer-km 150
~~~

## Безопасность

- Файл .env содержит персональные ключи и исключён из Git.
- Не добавляйте в публичный репозиторий исходные рабочие геоданные, если на их публикацию нет разрешения.
- Не вставляйте Secret Key в исходный код, логи, README или сообщения.

## План разработки

1. Базовая структура, настройки и геометрия СМП.
2. Проверка S3-подключения к CDSE.
3. Поиск Sentinel-1 EW GRDM с двойной поляризацией HH+HV через OData.
4. Скачивание полного SAFE-продукта и контроль целостности.
5. Защита от повторной загрузки, журналирование и ежедневный запуск через Windows Task Scheduler.
6. Постобработка SAR-продуктов (отдельный этап).
